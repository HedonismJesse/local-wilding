# Voiceover — console cut (~3min, 11 beats)

Challenge floor is 3–5 minutes; the cut covers all four spec beats
(local arm → gateway arm → live refusal → activity/evidence view).
Read it once through, one take, natural pace (~2s pause between
blocks — that's where the cut splits). Speak like you're showing
someone a tool, not pitching it.

---

**[0 — cold open]** — flat, matter of fact
"A one-billion-parameter model answered with sources. None of them
exist. This is the console that proves it."

**[1 — console reveal]** — light
"One harness, any OpenAI-compatible endpoint — Otari, a llamafile,
or your own gateway. Point it, and it probes models and tools
before you dispatch."

**[2 — real function]** — the core block, steady
"Real use first. Dispatch a claim — the feed streams every step:
the model the endpoint picked, the tools that ran server-side, the
settled cost. Then a receipt mints — model requested versus served,
tools declared versus ran, the hash of what was asked and answered,
linked to the raw response."

**[3 — demo / behind the scenes]** — slightly brighter, this is the payoff
"The demo button is the behind-the-scenes cut. Same task, two arms:
on the left a one-billion local model with no tools — it computes
eleven percent and calls it more than fifteen. On the right, the
gateway arm — code execution runs server-side, cost settles to six
decimals, every call receipted."

**[4 — enforcement]** — firm
"Set the allowance to a cent and the call refuses before it is ever
dispatched. The ledger counts what enforcement saved."

**[5 — receipt box]** — back to matter-of-fact
"Every dispatch mints a receipt — the served model, tools ran,
cost, the hash of prompt and answer, linked to raw evidence. The
whole box exports to JSON or CSV."

**[6 — evidence walk]** — slow, let the bytes read
"The receipt's raw link is the actual response body — the bytes the
endpoint returned, kept under evidence for every call. Recompute
the hash yourself; it matches."

**[7 — self-score]** — the instrument beat
"Then the harness grades its own submission — nine checks across
the beats the camera just watched. It only scores what the evidence
shows; unexercised claims score zero."

**[8 — honest limits]** — plain, no defensiveness
"The honest limits, printed where you can see them: replay mode
serves recorded evidence — no keys, no spend. Live needs your own
endpoint or key. And receipts mint per job; per-step is the next
pass."

**[9 — adoption]** — quick
"Clone, install three lines, run app dot py, click."

**[10 — close]** — settle on the last word
"Tools, budgets, receipts, a local control arm — and the honest
limits printed where you can see them."
